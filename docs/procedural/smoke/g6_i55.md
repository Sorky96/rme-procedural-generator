# I55 offline evaluation

Binding preregistration: `6251dbb`, [G6_METRICS.md](../G6_METRICS.md).
No generator, ranking A, I53 threshold, or acceptance condition is changed.
I51 and I51b retain their historical results. G6 remains open.

## Generate and freeze the common pool

Use Windows `py` and the newly built Candidate Rank. Every output path below
must resolve inside a directory named `scratchpad`. Inputs are read only.
No dependency installation or private data in Git is required.

```text
rtk proxy py -B -I docs/procedural/smoke/g6_i55.py measure EXE PROFILE_DIR COPY_INDEX scratchpad/i55-matrix
rtk proxy py -B -I docs/procedural/smoke/g6_i55.py diagnose PRIVATE_ROOT PROFILE_DIR scratchpad/i55-matrix scratchpad/i55-diagnostics.json
rtk proxy py -B -I docs/procedural/smoke/g6_i55.py package scratchpad/i55-matrix scratchpad/i55-evaluator scratchpad/i55-private/key.json
```

`measure` creates a new immutable input manifest **before** generation, binding
the executable, profiles, bands, I53 index and offline scripts by SHA-256. It
uses seeds 3001–3032 per profile, N=4, side 512, I51 settings, `--g5-levels`
and the same explicit M06/M19 copy index for both selections. Four independent
blocks run at most concurrently; reports are merged in original seed order.
Two full runs must have identical TSV and semantic PNG bytes. Errors retain
partial evidence and abort; there is no automatic retry or seed substitution.
Technical errors invalidate a run; after fixing the tool, retain that run and
use a new directory for the entire unchanged matrix and a new manifest.

Selection is independent of references used for evaluation. L2 is the first
admissible index; L3 is the admissible winner of A. Every seed must have four
complete candidates. A seed without an admissible result cannot produce a
pair and blocks full completion. Python independently checks all 26 ranking
contributions, the winner, candidate seeds and I53 counts/state. Reports retain
all hard failures and too-small I53 assessments with their denominators.

`--render-dir` in Candidate Rank exports the **post-repair measured surface**,
one pixel per tile, without PNG text metadata. Its palette includes all ten
surface kinds, including repaired bridges. The pre-level surface fingerprint
in TSV retains its original meaning. Export does not alter generation or TSV.

## Give only the evaluator directory to the rater

The package contains exactly 20 pairs (3001–3010 in each profile), including
identical selections. Random opaque IDs, a shuffled order, and a cryptographic
shuffle of five A/five B L3 assignments per profile are frozen in a separate
key before publishing views. There are no seeds, profiles, candidate indices,
control names, source paths, or pair summaries in the evaluator directory.
The key binds the matrix manifest and each public view hash. Do not share the
matrix, diagnostics or key with the rater; do not regenerate the assignment
after seeing ratings. Share only `i55-evaluator`.

Open `index.html` directly, without a server. Both sides show the same full
512×512 area with the same scale. The optional 1:1 scale applies to both.
The form supports keyboard radio choices, optional UTF-8 notes, draft export,
restore and complete export. It uses no CDN, external fonts, storage service
or network. The browser cannot force a download directory: save answers into
scratchpad and keep the exported file before closing. Drafts cannot be scored.

Answers use `g6-i55-ratings/1` with anonymous IDs, A/B/tie and optional notes
limited to 1024 UTF-8 bytes. This is a versioned local study record; no automatic
Adjust, profile switching or ranking update occurs. The existing production
I54 history is not overwritten or populated with synthetic feedback.

Only after **all 20 real ratings** have been submitted:

```text
rtk proxy py -B -I docs/procedural/smoke/g6_i55.py score scratchpad/i55-evaluator scratchpad/ratings.json scratchpad/i55-private/key.json scratchpad/i55-blind-result.json
```

The scorer validates complete unique ratings **before reading the key**,
checks key/package membership and view hashes, and reports ≥13/20 L3 wins,
ties, proportions per profile and identical pairs. Ties never count as wins.
No real ratings are generated by these tools. Synthetic ratings are test-only.
Semantic views assess terrain shape/distribution, not sprites or gameplay;
playability requires the separately registered regression and probes.

## Diagnostic comparison and unseen-family blocker

The bd89a30 intake/freeze/evaluate implementation is documented in
[g6_i55_intake.md](g6_i55_intake.md). It adds an explicit human-reviewed intake;
the diagnostic path below retains its historical meaning. No real new-family
sources have been accepted by this change.

`diagnose` reuses the audited G4 metric loader: source identities, receipts,
mapping, client, profiles, bands and definitional N/A rules remain unchanged.
It reports L2/L3 distances per seed/map/family, strict wins out of all 32,
ties, difference of medians, median paired difference, and coverage. It gives
M01, M05 and winter equal weight, with M11/M18 averaged within winter. M06/M19
are in-sample; M12–M17 are a separate related-family appendix. None can be
relabelled as unseen data. Diagnostic `atLeast23` fields describe the frozen
numeric threshold only; they cannot satisfy the unseen-family condition.

The diagnostic workflow does **not** accept an arbitrary metric JSON as proof of
new families. The frozen current manifest explicitly records an empty new
family list and BLOCKED status. No measurement on new families has occurred.
Before that work can proceed, supply and review:

- New map/semantic-bundle identities, client/assets/mapping and verification
  receipts, with documented provenance and permission to use them.
- A documented assertion that sources were not used in earlier analysis or
  tuning; multiple crops of one world must remain one family.
- G4 relatedness fingerprints and split evidence against all previously used
  families, with the existing generic-window and containment rules. A new
  alias or new crop alone is insufficient.
- An accepted manifest of aliases, hashes, families and evaluation units,
  frozen before revealing any L2/L3 distances. Bind metric inputs and
  relatedness evidence by hash through the offline intake; do not choose maps
  after results.

The required quantitative decision remains ≥23/32 strict L3 wins **separately
for each profile on new families**. Known-map diagnostics and the blind test
cannot replace it. Missing sources or a reference with no known metric blocks
comparison; N/A contributes the fixed cap without changing 26 positions.
The report exposes known/varying positions to make weak coverage visible.
